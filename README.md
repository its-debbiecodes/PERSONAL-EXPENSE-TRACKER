#  ====== 💰 PERSONAL EXPENSE TRACKER =====   

## 👋 About
This tracker helps users see where they spend their money, all in one place. Users can add, search, view, calculate, and delete their expenses.

## 💾 Features
This tracker contains a menu  for choosing either to 
- add a new expense
- view all your recorded expenses
- calculate your total expenses
- search for expenses using the category
- search for expenses using the name
- delete expenses

## 💻 Tech knowledge used
- Functions
- Modules
- While loop
- For loop
- If/Else
- JSON and file handling
- datetime import and conversion to JSON
- Error & Exception Handling
- F-strings & Text Alignment Modifiers

## 📂 File Architecture
* main.py - This is where the while True menu run loop is stored. This is what the user sees most of the time.
* storage.py - This is where file handling takes place: file creation, file adding, deleting, and everything JSON.
* task.py - This is where our functions live for easy navigation and tidy code; a lot of backend happens here.

## 🚀 How to Run
1. Clone this repository or download the source code files.
2. Ensure you have Python 3.x installed on your computer.
3. Open your terminal/command prompt, navigate to the project folder, and run:
   ```bash
   python main.py
   ```
